## 主控裁决及代价

1. 在当前 checkout 实施、不建分支，验证前不提交；避免改变用户指定基线，代价是验证期间以未提交
   文件保存工作。验证后按用户新增授权提交／推送当前分支，原有截图和设计稿继续留在本地。
2. 按批准方案允许不重叠文件并行，最多三个子 Agent；所有 pytest 串行，代价是测试等待时间增加。
3. 技能临时工作区改用专用系统临时目录，不新增项目顶层目录；关键记录另保存在本报告目录，
   临时原始日志仍保留但可能随系统清理丢失。
4. 隔离器只允许 Windows `socket.socketpair` 内部回环连接且排除 5037；普通网络仍禁止。
   该规则用于合成管道测试，不代表真实网络验证；误配置会削弱隔离，因此不泛化为允许回环网络。
5. 关闭截止时间后，只对未 join 的真实 QObject 子 QThread 延迟父树销毁；事件循环继续运行。
   代价是永久卡住的 Qt worker 可让窗口一直显示关闭中；强杀或销毁活动 QThread 不可作为成功退出。
   普通 Python／进程残留截止语义和升级失败门禁保持。
6. MobilePerf 保留原 `is_running()` 的模式线程与进程语义；零预算停止测试需实际 join 后再断言。
   资源活性与当前报告完成另用明确谓词，代价是消费者必须选对判断，不能互相替代。
7. 合成原生进程测试允许项目解释器对应的基础 `python.exe/pythonw.exe`，不开放任意外部进程。
   这些子进程不继承父进程 Python 审计钩子，所以已单独核对其代码、临时路径与 finally 清理；
   不能把此白名单视为操作系统安全沙箱。
