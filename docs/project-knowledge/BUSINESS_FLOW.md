# 主要业务流程

本页只保留用户触发、主流程、失败/取消和清理语义。模块位置见
[MODULE_MAP](MODULE_MAP.md)，数据生命周期见 [DATA_FLOW](DATA_FLOW.md)，线程与应用关闭见
[ARCHITECTURE](ARCHITECTURE.md)。

## 1. 启动、导航与设备发现

- **触发**：运行 GUI 入口；worker 和打包自检子模式不会创建主窗口。
- **主流程**：GUI 入口在 QApplication 创建前读取显示缩放，创建应用后先安装 Qt、Fluent 和应用翻译，
  再应用字体、主题并创建 MainFrame；构建
  Home、三个业务宿主页、Tasks、Settings 六个物理页面。主左栏直接登记九个业务功能，
  加上首页、任务和设置共十二个一级入口；宽屏显示完整菜单，窄屏显示图标栏并可打开覆盖菜单。
  MainFrame 中宿主和面板的 Pivot/ComboBox 均保持隐藏；独立宿主仍保留原导航接口。复杂功能按路由、
  设备和代次懒创建；ADB 在后台检测执行环境，服务可用即按设置开始设备发现，测速继续异步完成。
  设置页展示适用范围并支持重新检测和本次运行的原生开关，详见
  [ADB 自动适配](../guides/ADB_FAST.md)。返回按钮使用 MainFrame 的语义历史，
  因而同一物理宿主页内的功能入口也逐级返回。缺少设备时保留目标功能空态，通过全局栏选择；
  打开设备选择弹层不切换页面，也不添加导航历史。
- **页面呈现**：主页面直接展示功能内容，不再保留标题、说明横幅或为标题预留高度；
  功能分组、空态提示和操作控件继续显示，页面名称仍用于导航与辅助技术。
  主题入口统一位于侧栏“设置”上方：收起时单击图标切换，展开时显示“深色”开关。
  切换同步设置页和持久化配置，不改变当前页面、设备会话或导航历史；“跟随系统”仍在设置页选择。
  语言和显示缩放保存后重启生效；翻译器随本次应用存活，不通过重建正在持有设备任务的页面即时切换。
  设置选项、资源生成方式和平台限制见 [构建与运行](../guides/BUILD_AND_RUN.md#启动)。
- **失败与恢复**：字体、字号和窗口尺寸在边界外时回退到安全值；扫描失败只标记 unavailable，
  保留最后成功设备列表，不自动重启 ADB Server。慢速元数据回调只有在设备拓扑 generation 仍匹配
  时才写入和发布。MENU 状态跨入 1120 像素宽屏断点时会归位为常驻左栏，导航动画结束后按最终
  viewport 同步响应式布局。

### Workspace 路由目录

下表是 Workspace 可见路由的单一事实来源。首页、设置、任务中心和设备概览不显示顶部设备栏；连接、刷新以及
“更多”中的断开所选设备集中在设备概览；设备信息随发现查询自动更新，在设备卡片中展开查看。
功能页顶部呈现页面名称：批量工具提供操作设备多选入口；
固定设备功能在按钮上明确显示当前设备，弹层统一使用单选或多选设备列表；适用的关闭图标留在按钮旁。具体范围与通知规则见
[操作反馈指南](../guides/OPERATION_RESULTS.md#统一操作设备入口)。
单选页面一次勾选同时提交操作目标和切换会话；性能页保留多选及逐设备配置。会话候选和运行锁由所属宿主提供。
窄窗优先收起页面名称、省略过长的设备名称，功能入口保持单行，完整含义保留在可访问名称与悬停提示中。
会话在线、离线、未选为操作目标、等待选择和关闭状态通过会话控件说明提供，不再单独显示重复徽标。
性能页点击会话行仅选择展示的设备，不授予设备操作资格。更改批量复选集不会重定向已经运行的会话。

| 操作类型 | 设备目标与准入条件 | 取消选择后的行为 |
| --- | --- | --- |
| 应用/系统批量动作 | 复制并去重当前已选在线设备 | 拒绝新动作；本地配置可编辑 |
| 文件、应用管理、Logcat、性能新操作 | 固定会话设备必须同时在线且属于当前已选目标 | 缓存可查看，按钮、右键、双击、回车、弹窗返回及异步续发均拒绝新设备命令 |
| 远程镜像、按键与手势 | 复制当前已选在线设备集合；发现状态须为 ready | 已运行镜像保留原设备；没有可用目标时拒绝新操作 |
| 概览文件/远程/应用快捷入口 | 该行设备已选且发现状态 ready | 保留选择和详情控件，快捷入口禁用；提交再次核对 |
| 停止、取消和必要清理 | 使用任务启动时保存的设备与批次 | 始终可停止原任务；不改向后来选择的设备 |
| 连接、发现与概览属性读取 | 已验证连接地址或后台在线快照 | 不依赖操作目标，用于发现和选择设备 |
| 本地查看、导出、配置 | 不发送设备命令 | 不要求选择设备 |

| 路由 | 主内容 | 设备上下文 | 生命周期 |
| --- | --- | --- | --- |
| `devices/overview` | 设备卡、连接摘要和针对该设备的文件/远程/应用入口 | 展示缓存元数据和全局选择快照 | 随主窗口创建；不发起额外查询 |
| `devices/files` | 文件管理 | 固定一台设备 | 按设备懒创建；显式关闭后释放 |
| `devices/remote` | 远程控制：屏幕镜像与按键手势 | 多选设备 | 复用 RemotePanel，按启动批次保留各设备进程，不进入 FeatureSessionRegistry |
| `apps/overview` | 应用与诊断：常显应用包管理、Monkey、报告日志和诊断 | 批量目标 | 复用 AppPanel 概览与唯一包名输入 |
| `apps/manager` | 已安装应用列表与列表选中项操作 | 固定一台设备 | 列表按设备懒创建并可关闭 |
| `apps/media` | 截图与屏幕：文本发送、截图、录屏与截图查看器 | 查看结果无需设备；新设备操作使用批量目标 | 使用空设备键懒创建；可在后台追加结果 |
| `system/overview` | 系统工具：Shell、Intent、Android 设置、重启、网络、电池、模拟器 | 批量目标 | 复用 SystemPanel，九张卡片在同一滚动页面 |
| `system/logcat` | 实时 Logcat | 固定一台设备 | 按设备懒创建；关闭会话才停止资源 |
| `system/performance` | 性能采集 | 固定一台设备 | 按设备懒创建；关闭进入异步停止屏障 |

Settings 中的 About 随 SettingsPage 创建，不属于 Workspace 路由。未知 section/feature 会在主页面
切换前被拒绝。

旧入口作为兼容别名保留，不新增可见页签或复制功能会话：`devices/remote-control → devices/remote`；
`apps/packages → apps/manager`；`apps/diagnostics`、`apps/monkey → apps/overview`；
`system/settings`、`system/device`、`system/connectivity → system/overview`。
排队激活和返回历史使用解析后的正式路由。

## 2. 连接设备与读取信息

- **触发**：用户输入 ip:port/[IPv6]:port 连接，或请求刷新设备。
- **主流程**：UI 与 Controller 校验目标，ADB 执行 connect/devices/getprop 等命令，Controller
  汇总属性并更新 DeviceStore 缓存，只有合法 IP 连接历史进入持久化，具体边界见
  [设备发现与元数据流](DATA_FLOW.md#设备发现与元数据流)；随后更新全局设备栏、概览和三个业务主页面。全局设备多选弹层
  提交复选集合，隐藏 DeviceManager 的原列表继续作为兼容接口的状态来源；不增加第二套持久化
  选择。单设备深层功能使用独立的会话设备，Remote 直接使用已选在线目标集合。会话候选列出全部在线设备
  并保留已有离线会话；恰好一个已选在线批量目标时可沿用该目标；多个批量目标或未选择操作目标时，
  首次打开单设备功能要求明确选择目标，单选弹层一次完成选择与准入；性能页首次多选后打开所选设备之一供配置。仅有一台在线设备不再代表已选择。没有明确目标时保留原功能路由，并显示等待选择的空态；
  后台宿主只刷新候选和等待提示，不提前创建或激活目标页，首次进入前台或用户明确选定后再恢复。
  没有在线候选时，空态主按钮前往设备概览连接或刷新；存在候选时使用功能页设备下拉框，不打开空多选列表。
- **失败与恢复**：不完整目标在执行前拒绝；超时和非零退出形成失败结果。发现列表只接纳 ADB
  状态为 `device` 的设备，offline/unauthorized 不进入在线候选；已有功能会话可保留离线设备。
  扫描查询失败保留最近成功的设备列表；这与扫描成功但返回空列表的正常空态不同。
  设备重启命令成功仅确认请求提交；超时返回结果未知，重试前须检查设备状态。延迟刷新只更新
  设备列表，不据此宣告重启完成。原生 reboot 和 start-server 使用普通命令预算以容纳客户端启动。
- **功能位置**：连接弹层只列出已保存的 IP 地址历史并支持回车连接，继续校验真实目标而不是显示标签；
  全选、清空选择在多选弹层中。批量安装位于应用与诊断顶部常显的应用包管理卡，重启设备位于系统工具，重启本机
  ADB 位于 Settings 的 ADB 维护卡；均复用既有信号和业务边界。
- **设备概览**：扁平设备行的复选框或非按钮区域双击，经 DeviceManager 提交全局目标；再次双击取消。
  点击行内文件、远程或应用按钮必须先选中该台，只打开该设备的功能会话，不修改其他批量选择。
  名称、连接状态和电量位于行首；系统、屏幕、内存与存储组成四项摘要；CPU、硬件、连接标识、密度和剩余容量放入可展开详情。
  设备概览保留状态文字，并用主题语义色区分在线、扫描和连接待确认；功能页不重复显示在线总数。
  品牌、型号和 Android 版本来自已加载的 DeviceStore 快照；后台刷新在同一次有超时的只读 Shell 中
  补充 SDK、CPU、硬件、屏幕、内存、存储和电池，动态字段仅存主窗内存，离线清除，不改变配置格式。
  属性按刷新时的快照展示，缺失值隐藏；新快照缺失的动态字段会清除，不能继续显示旧电量冒充新结果。
  连接与刷新位于页面内设备摘要旁，空态和已有设备时都可使用；连接弹层锚定页内按钮。
  应用入口保留在各设备卡内，页面底部不再重复提供批量应用入口。

## 3. 应用管理与安装批次

- **触发**：安装、卸载、启停、清数据、权限、备份/恢复、批量安装或打开 App Manager。
- **主流程**：普通动作经 Controller/ADB model；App Manager 在固定设备的内嵌功能会话中用
  worker 加载列表和详情。安装批次为每次请求创建 operation 和 unit 身份，按 owner/generation
  接受结果，支持部分失败、取消和失败项重试。
  应用包管理卡在应用与诊断页顶部常显，复用 AppPanel 的原控件与信号；切页或关闭列表会话均保留输入。
  应用操作、Monkey 与诊断读取同一包名字段和历史，不再创建额外的目标应用输入。
  应用管理的列表操作使用原生 CommandBar，次要命令随宽度进入更多菜单；按钮和菜单共享同一 Action 可用态。
  嵌入时筛选行不重复显示设备状态徽标，搜索框说明与底部操作提示保留准入原因。
  批量动作在提交时重新取得去重的已选在线目标，无目标时按钮与快捷提交均拒绝执行；本地 APK 解析保留可用。
  “获取当前应用”只允许查询一个目标并禁止重复提交；请求期间编辑输入或变更设备后，晚到结果不覆盖当前输入。
- **列表与详情查询**：应用列表、详情与权限读取支持执行中取消；应用修改、安装和备份保留
  各自原有执行边界。详情沿用可见项目优先、每批最多 30 个包、成功缓存和请求代次隔离。
  批量查询及解析兼容时的逐项补查共享一次截止时间；取消、失败或预算耗尽不继续叠加查询。
  已成功的详情保留，失败项目不写成空的成功缓存，也不在本轮 80 毫秒续发中反复排队；
  使用现有刷新入口开始新一轮重试。页面关闭仍通过 worker 等待屏障确认线程退出。
  禁用状态查询失败时不把所有应用猜测为 Enabled；独立详情和权限读取失败或包不存在时，
  不发布空的成功结果，由已有失败提示和刷新入口处理。
- **应用图标**：切到图标列表后，`AppManagerIcons` 按当前可见区域每批最多读取 12 个包。
  `AppManagerWorker` 在后台调用 `services/app_icons.py`，由临时设备端 DEX 工具将当前用户的
  原生 Drawable 渲染为 96×96 PNG，兼容自适应与矢量资源；Qt 图像对象只在主线程创建。
  缓存归当前设备页面所有，切换视图复用缓存，刷新列表使旧缓存和在途结果失效。
  离线、切走页面或关闭时停止追加任务，关闭沿用 worker 等待屏障。
  读取失败保留占位图标，悬停提示刷新重试，不将读取失败视为成功。工具只推送至随机临时路径，
  本批结束、失败或取消时尝试删除该文件，清理失败会回报失败；每条命令有超时，取消在当前命令结束后生效。
  设备端另设 15 秒退出保护，即使 PackageManager 或图标绘制卡住也不会持续留在后台。
- **失败与清理**：输入或目标校验失败时不启动 worker；worker 在开始前收到中止请求就不执行设备
  操作。备份先写 staging，恢复安装失败不会报告成功；晚到或错代批次结果直接丢弃。高影响动作
  当前不二次确认，安全边界依赖目标校验和真实失败传播。
  应用列表因设备未勾选或离线而拒绝刷新时，只更新操作提示并保留原加载状态；未实际发起加载
  不显示新的加载错误行，也不覆盖上一次真实加载失败的原因与重试入口。
  应用重启只有在 force-stop 成功后才执行启动；停止失败保留原因并终止后续操作。

## 4. Monkey、截图、录屏与诊断

- **Monkey**：位于应用与诊断页。点击“获取包信息”只读查询；点击开始先保存所选设备、包名和
  参数快照，再在既有 worker 中逐台读取安装路径和包元数据，单条命令超时为 5 秒。包名为空时识别
  各设备前台应用；无法识别或包名不一致时要求明确填写。同包版本不同可继续；单设备直接显示版本，
  多设备默认显示核对数量及版本差异摘要，点击“展开设备明细”查看逐台版本，无需重新查询。
  只有全部结果完整且输入仍匹配时才启动原 Monkey 批次；失败、取消、目标或输入变化、关闭及晚到结果
  均不能启动旧请求。取消在每条查询前后检查，当前命令结束后释放后台执行。启动后继续跟踪进程和
  前台包；用户中止或连续探测失败会停止进程并清理日志资源，未知前台状态不按成功处理。
  每台设备在任务排队前登记批次，排队期间停止后不再启动进程；启动、停止和收尾校验同一批次归属，
  晚到的旧批次停止不会影响新批次。停止入口沿用启动时保存的设备，清空或更改当前选择不会重定向停止操作。
- **截图**：每批请求按 operation/task 隔离，校验目标、路径和 PNG artifact 后汇总。成功结果后台
  追加到 ScreenshotPage；不在该页时只显示“查看结果”提示，不抢占导航。取消会原子标记未完成
  unit，并中断当前截图命令，晚到回调被丢弃。二进制采集按设备运行策略自动选择执行方式，
  在总计 30 秒预算内写同目录临时文件、后台完整解码，再原子发布；失败不覆盖已有目标图片。
- **文本与屏幕工具**：位于截图与屏幕页顶部，发送文字、截图和新录屏需要已选设备；无设备时仍
  可浏览已有截图。停止录屏继续使用启动时保存的设备集合，切页或清除截图不会取消已有录屏。
- **图片浏览**：Fluent FlipView 每页显示一张原比例截图，多图以圆点分页并显示当前序号与总数。
  文件名位于画布左上，圆点与数量位于左下，缩放比例位于右下，不再占据画布之外的底部行。
  命令栏支持添加本地图、旋转、缩放、适应窗口、信息、复制、定位文件和删除全部；窄屏操作进入更多菜单。
  删除全部作用于当前图库加载的文件（含本地添加图片），右键菜单保留单张删除；删除失败项保留并报告数量。
  旋转按图片保留在当前会话，仅改变预览与复制结果，不覆写源文件；放大后可拖动查看。
  批次追加及删除后同步主图与圆点，切页保留图片状态；文件名省略时通过提示获取完整路径。
- **录屏与诊断**：录屏按批次管理启动、停止和拉取；本地视频拉取成功但远端清理失败时保留文件并
  单独报告清理错误。bugreport 解压使用安全 ZIP 边界。
  录屏 model 在进程创建前校验时长、码率和成对的宽高参数，非法数值不会进入设备 shell。

## 5. Live Logcat

- **触发**：从左栏“实时 Logcat”为一台设备打开日志会话，可选择包过滤。
- **主流程**：worker 消费单一 logcat 流并在 producer 侧批量；包过滤周期刷新全部 PID，只发布
  当前 generation 的匹配行。切走页面暂停绘制但继续消费。
- **界面**：嵌入时直接展示日志功能；中文过滤工具、采集控制和状态分层显示，工具条按宽度换行。
  日志使用独立主题背景和等级颜色；正在阅读历史时追加不会拉回底部，回到底部后恢复跟随。
  “停止采集”保留当前会话和内容；顶部关闭图标（悬停显示“关闭日志会话”）释放该会话。
  输出框填满当前视口剩余高度，隐藏的其他会话不参与测高；切页返回保留阅读锚点、换行和跟随状态。
- **失败与清理**：包未运行或 PID 查询失败时 fail-closed 并重试，不退化为其他应用日志。
  “停止采集”经 TaskSupervisor 停止 logcat worker 及其进程、reader 和 PID 刷新线程，
  保留页面与日志；显式关闭会话或应用关闭还会释放会话资源，归零前保持释放屏障。

## 6. 文件浏览与传输

- **触发**：从左栏“文件管理”或设备概览快捷入口打开固定设备的 File Explorer，执行浏览、pull/push、
  编辑、复制、移动、删除、chmod、APK 安装或脚本操作。
- **主流程**：服务层校验名称和路径；短命令走 CommandRunner，传输走 ProcessRunner；成功后刷新
  目录。切走页面保留路径、预览和仍需继续的任务。
  嵌入页直接展示文件功能；文件类型列显示图标，悬停和辅助信息保留完整类型，排序和目录进入行为不变。
  预览只在打开内容时占用空间；关闭后文件列表恢复全宽，晚到结果不会重新打开预览。
- **失败与清理**：未选设备显示空态，离线会话禁止新操作；非法名称、.. 和失败结果不会进入
  成功刷新。显式关闭会话中止 worker，尚未进入执行体的任务不会启动。
  文件列表解析保留名称中的连续空白和尾部空白，不把合法文件名中的错误关键词当作命令诊断。

## 7. Remote

- **触发**：在左侧进入远程控制，勾选一台或多台设备后使用屏幕镜像、按键和手势。
- **主流程**：Remote 直接使用右上角已选在线目标。启动时固定设备批次，逐台预检、生成 LaunchPlan，
  ProcessRunner 为各设备启动独立 scrcpy；stderr/FPS reader 和 watchdog 更新状态。按键与手势
  固定当次目标并发送给各设备的持久 ADB shell。改变选择不重定向已启动镜像，停止清理仍使用原批次。
- **失败与清理**：没有可用目标时拒绝新操作；单台预检或启动失败不阻断其他设备。关闭时先停止输入
  准入，停止原批次进程并等待 executor、warmup、reader 和焦点线程，最后关闭持久输入会话；
  非 Windows 缺少 PATH scrcpy 时明确失败。

## 8. MobilePerf

- **触发**：从左栏“性能采集”选择设备和包，配置采样后启动。
- **多设备**：勾选多台设备或存在多个保留会话时，列表分别显示设备状态、预计进度和用时。
  点击一行查看对应参数和日志，启动/停止只作用于当前查看设备；选择多台不会自动批量开始。
  已运行设备取消勾选或离线后仍保留状态和停止入口。顶部设备栏不再重复提供“结束性能采集”。
- **主流程**：页面生成运行配置，Runner 创建独立临时目录和子进程，双管道 reader 排空输出；
  只有退出码成功且本次生成非空报告时才显示完成。切走页面不停止采集。
  worker 继承启动时的 ADB 执行模式并独立验证目标设备，同步采样查询自动选择快速通道；
  具体兼容范围及停止收尾契约见 [ADB 自动适配](../guides/ADB_FAST.md#mobileperf-采集进程)。
  启用同时运行 Monkey 时，创建实际进程后才标记运行；合并标准错误以持续读取启动及运行诊断。
  所请求的 Monkey 启动、运行或停止失败会在其他监控器收尾后传回子进程退出状态，不能记为成功。
- **结果查看**：日志/图表切换属于当前设备页面；图表在采集结束后读取本次结果目录的 CPU、内存、
  FPS/jank 和流量 CSV，不在运行中持续绘图。缺失指标和坏行不填成有效数据，重复加载替换旧曲线；
  图表可用不等于采集成功，结束状态仍由本次报告与退出结果判断。结果目录与归档附件沿用本地文件入口。
- **进度与停止**：百分比按已用时间与计划时长估算，结果确认前最多为 99%；达到计划时长但
  尚未完成，或正在停止并生成报告时，改为不定进度等待，不提前显示 100%。成功确认后才完成，
  主动停止显示“已停止”并保留已生成结果，不显示正常完成。
- **失败与清理**：启动失败立即恢复 UI；停止先写 stop 标记并等待报告，超时后强制停止。旧报告、
  空报告或非零退出不能伪装为成功。
  停止调用返回时若进程仍存活，保留采集会话与配置锁定并允许重试停止；应用关闭同时等待
  停止线程和采集进程，未退出资源保持明确的超时状态。

## 9. 任务中心

- **活动项**：OperationManager 当前快照提供进度和取消操作；普通命令的 ActionResult 另提供
  “查看执行中的操作”入口，定位该请求的逐台过程。两类都没有在途项时显示一行空态；任务中心
  不等同于所有后台资源的清单，Monkey、录屏和性能采集仍由各自页面与生命周期管理。
- **测试结果**：默认展示 Monkey 和性能测试的跨重启归档；可搜索包名或日期，按类型和状态筛选。
  选中记录显示摘要、可用设备/版本、参数与附件；打开附件使用显式本地路径，缺失文件给出提示。
  “载入参数”只回填相应页面，不恢复旧设备、不启动测试；性能页暂无目标时保留一次性路由参数，
  用户选择当前设备后才应用。正在运行的表单拒绝载入。
- **命名方案**：在 Monkey 或性能页保存当前参数，以名称载入或另存，同名保存更新原方案。
  当前测试类型没有方案时，下拉框提示先保存并禁用，保存入口仍可用。
  保存后选中该方案，取消命名不改动原选择或参数；载入只回填，不自动开始测试。两类方案分别展示；
  删除方案不会删除结果或产物。运行快照在开始时固定，结束后至多保存一次。
  性能主动停止/关闭记为已取消并保留已生成附件；成功必须满足本次非空报告和正常退出。
  Monkey 沿原批次终态和停止确认屏障归档；关闭栅栏拒收的终态通过模型有界缓存恢复，未确认
  资源退出的记录标为不完整，不伪装成正常完成。
- **本次操作**：Controller 的 ActionResults 聚合请求与逐台结果，经 action_result_changed 和
  ActionFeedbackPresenter 推送到任务中心的 ActionResultView，保留状态、正文及文件入口，
  与测试结果在同一区域切换显示；普通页面使用分级 Toast，过程消息不生成成功历史。
  本次结果在应用重启后清空，兼容历史与正式存储的区别见 [数据存储](DATA_FLOW.md#测试结果与方案)。
  设备详情留在设备页，后台通知可返回对应请求。
  全功能归属、保留边界与交互说明见 [操作结果与应用诊断](../guides/OPERATION_RESULTS.md)。
- **取消**：按钮总是调用 OperationManager.request_cancel()；MainFrame 当前只为安装批次和截图
  追加资源停止路由，其他任务是否真正停止取决于其自身执行边界。

## 10. 页面会话与应用关闭

切页保留会话与后台任务，显式关闭才释放页面；应用退出按停止准入、广播停止、后台等待、
补交测试结果与最终落盘收尾。超时和保存失败不能描述为成功。
详细对象归属和关闭顺序见 [ARCHITECTURE](ARCHITECTURE.md#应用关闭)。

## 11. 应用更新检查

- **入口**：设置 → 关于 → ADBLab 卡片。应用信息和更新状态合并显示，当前版本只展示一次。
  启动或进入设置页不访问更新源，用户点击“检查更新”
  才查询公开正式发布；当前版本始终读取 `utils/app_metadata.py`。
- **结果**：按三段数字比较正式版本，区分发现新版、版本相同、本地领先及失败。新版显示
  发布日；成功检查时间使用本机时间。发布页或下载按钮只在显式点击时打开浏览器，指向
  已校验的具体版本页面；尚无结果时指向项目发布列表。应用不下载、解压或自动替换程序。
- **失败与重试**：网络、TLS、超时、限流、服务不可用和异常数据分别显示可操作提示；失败
  不能当作“已是最新版”。重试失败保留上次确认的发布并标记为历史结果。只允许一个在途请求，
  请求整体最多 10 秒，响应正文最多 256 KiB；普通检查冷却 5 秒，限流至少等待一分钟，并
  尊重服务端更晚的重试时间。更新接口拒绝重定向，发布链接必须匹配本项目及本次标签。
- **保留范围**：切页保留检查结果，重启清空；无自动检查开关、额外持久化配置或设备目标依赖。
  资源停止与释放边界见 [ARCHITECTURE](ARCHITECTURE.md#应用关闭)。
