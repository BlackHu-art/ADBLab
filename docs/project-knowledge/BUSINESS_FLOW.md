# 主要业务流程

本页只保留用户触发、主流程、失败/取消和清理语义。模块位置见
[MODULE_MAP](MODULE_MAP.md)，数据生命周期见 [DATA_FLOW](DATA_FLOW.md)，线程与应用关闭见
[ARCHITECTURE](ARCHITECTURE.md)。

## 1. 启动、导航与设备发现

- **触发**：运行 GUI 入口；worker 和打包自检子模式不会创建主窗口。
- **主流程**：GUI 入口在 QApplication 创建前读取显示缩放，随后创建主题和 MainFrame；构建
  Home、三个业务宿主页、Tasks、Settings 六个物理页面。主左栏直接登记九个业务功能，
  加上首页、任务和设置共十二个一级入口；宽屏显示完整菜单，窄屏显示图标栏并可打开覆盖菜单。
  MainFrame 中宿主和面板的 Pivot/ComboBox 均保持隐藏；独立宿主仍保留原导航接口。复杂功能按路由、
  设备和代次懒创建；ADB 在后台预热并按设置执行设备发现。返回按钮使用 MainFrame 的语义历史，
  因而同一物理宿主页内的功能入口也逐级返回。缺少设备时保留目标功能空态，通过全局栏选择；
  打开设备选择弹层不切换页面，也不添加导航历史。
- **失败与恢复**：字体、字号和窗口尺寸在边界外时回退到安全值；扫描失败只标记 unavailable，
  保留最后成功设备列表，不自动重启 ADB Server。慢速元数据回调只有在设备拓扑 generation 仍匹配
  时才写入和发布。MENU 状态跨入 1120 像素宽屏断点时会归位为常驻左栏，导航动画结束后按最终
  viewport 同步响应式布局。

### Workspace 路由目录

下表是 Workspace 可见路由的单一事实来源。首页、设置和设备概览不显示顶部设备栏；其他主页面支持多选操作目标、连接、
刷新，以及“更多”中的设备信息和断开连接。固定设备功能在同一设备栏中额外显示“当前查看”，会话候选和运行锁
由所属宿主提供；“当前查看”仅选择展示的会话，不授予设备操作资格。更改批量复选集不会重定向已经运行的会话。

| 操作类型 | 设备目标与准入条件 | 取消选择后的行为 |
| --- | --- | --- |
| 应用/系统批量动作 | 复制并去重当前已选在线设备 | 拒绝新动作；本地配置可编辑 |
| 文件、应用管理、Logcat、性能、远程新操作 | 固定会话设备必须同时在线且属于当前已选目标 | 缓存可查看，按钮、右键、双击、回车、弹窗返回及异步续发均拒绝新设备命令 |
| 概览文件/远程/应用快捷入口 | 该行设备已选且发现状态 ready | 保留选择和详情控件，快捷入口禁用；提交再次核对 |
| 停止、取消和必要清理 | 使用任务启动时保存的设备与批次 | 始终可停止原任务；不改向后来选择的设备 |
| 连接、发现与概览属性读取 | 已验证连接地址或后台在线快照 | 不依赖操作目标，用于发现和选择设备 |
| 本地查看、导出、配置 | 不发送设备命令 | 不要求选择设备 |

| 路由 | 主内容 | 设备上下文 | 生命周期 |
| --- | --- | --- | --- |
| `devices/overview` | 设备卡、连接摘要和针对该设备的文件/远程/应用入口 | 展示缓存元数据和全局选择快照 | 随主窗口创建；不发起额外查询 |
| `devices/files` | 文件管理 | 固定一台设备 | 按设备懒创建；显式关闭后释放 |
| `devices/remote` | 远程控制：屏幕镜像与按键手势 | 固定一台设备 | 复用 RemotePanel，不进入 FeatureSessionRegistry |
| `apps/overview` | 截图与诊断：常显应用包管理、截图录屏、Monkey、报告日志和诊断 | 批量目标 | 复用 AppPanel 概览与唯一包名输入 |
| `apps/manager` | 已安装应用列表与列表选中项操作 | 固定一台设备 | 列表按设备懒创建并可关闭 |
| `apps/media` | 截图结果 | 不需要设备 | 使用空设备键懒创建；可在后台追加结果 |
| `system/overview` | 系统工具：Shell、Intent、Android 设置、重启、网络、电池、模拟器 | 批量目标 | 复用 SystemPanel，九张卡片在同一滚动页面 |
| `system/logcat` | 实时 Logcat | 固定一台设备 | 按设备懒创建；关闭会话才停止资源 |
| `system/performance` | 性能采集 | 固定一台设备 | 按设备懒创建；关闭进入异步停止屏障 |

Settings 中的 About 随 SettingsPage 创建，不属于 Workspace 路由。未知 section/feature 会在主页面
切换前被拒绝。

旧入口作为兼容别名保留，不新增可见页签或复制功能会话：`devices/remote-control → devices/remote`；
`apps/packages → apps/manager`；`apps/diagnostics`、`apps/monkey → apps/overview`；
`system/settings`、`system/device`、`system/connectivity → system/overview`。
排队激活和返回历史使用解析后的正式路由。

## 2. 连接设备与读取信息

- **触发**：用户输入 ip:port/[IPv6]:port 连接，或请求刷新设备。
- **主流程**：UI 与 Controller 校验目标，ADB 执行 connect/devices/getprop 等命令，Controller
  汇总属性并写入 DeviceStore，随后更新全局设备栏、概览和三个业务主页面。全局设备多选弹层
  提交复选集合，隐藏 DeviceManager 的原列表继续作为兼容接口的状态来源；不增加第二套持久化
  选择。单设备深层功能和 Remote 使用独立的会话设备。会话候选列出全部在线设备
  并保留已有离线会话；恰好一个已选在线批量目标时可沿用该目标；多个批量目标或未选择操作目标时，
  首次打开功能要求明确选择当前查看的设备。仅有一台在线设备不再代表已选择。没有明确目标时保留原功能路由，并显示等待选择的空态；
  后台宿主只刷新候选和等待提示，不提前创建或激活目标页，首次进入前台或用户明确选定后再恢复。
- **失败与恢复**：不完整目标在执行前拒绝；超时和非零退出形成失败结果。发现列表只接纳 ADB
  状态为 `device` 的设备，offline/unauthorized 不进入在线候选；已有功能会话可保留离线设备。
  扫描查询失败保留最近成功的设备列表；这与扫描成功但返回空列表的正常空态不同。
- **功能位置**：连接地址历史和回车连接保留在设备栏的连接弹层，继续校验真实目标而不是显示标签；
  全选、清空选择在多选弹层中。批量安装位于截图与诊断顶部常显的应用包管理卡，重启设备位于系统工具，重启本机
  ADB 位于 Settings 的 ADB 维护卡；均复用既有信号和业务边界。
- **设备概览**：扁平设备行的复选框或非按钮区域双击，经 DeviceManager 提交全局目标；再次双击取消。
  点击行内文件、远程或应用按钮必须先选中该台，只打开该设备的功能会话，不修改其他批量选择。
  名称、连接状态和电量位于行首；系统、屏幕与内存分栏显示；CPU、硬件、连接标识、密度和剩余容量放入可展开详情。
  品牌、型号和 Android 版本来自已加载的 DeviceStore 快照；后台刷新在同一次有超时的只读 Shell 中
  补充 SDK、CPU、硬件、屏幕、内存、存储和电池，动态字段仅存主窗内存，离线清除，不改变配置格式。
  属性按刷新时的快照展示，缺失值隐藏；新快照缺失的动态字段会清除，不能继续显示旧电量冒充新结果。
  连接与刷新位于页面内设备摘要旁，空态和已有设备时都可使用；连接弹层锚定页内按钮。
  应用入口保留在各设备卡内，页面底部不再重复提供批量应用入口。

## 3. 应用管理与安装批次

- **触发**：安装、卸载、启停、清数据、权限、备份/恢复、批量安装或打开 App Manager。
- **主流程**：普通动作经 Controller/ADB model；App Manager 在固定设备的内嵌功能会话中用
  worker 加载列表和详情。安装批次为每次请求创建 operation 和 unit 身份，按 owner/generation
  接受结果，支持部分失败、取消和失败项重试。
  应用包管理卡在截图与诊断页顶部常显，复用 AppPanel 的原控件与信号；切页或关闭列表会话均保留输入。
  应用操作、Monkey 与诊断读取同一包名字段和历史，不再创建额外的目标应用输入。
  批量动作在提交时重新取得去重的已选在线目标，无目标时按钮与快捷提交均拒绝执行；本地 APK 解析保留可用。
  “获取当前应用”只允许查询一个目标并禁止重复提交；请求期间编辑输入或变更设备后，晚到结果不覆盖当前输入。
- **应用图标**：切到图标列表后，`AppManagerIcons` 按当前可见区域每批最多读取 12 个包。
  `AppManagerWorker` 在后台调用 `services/app_icons.py`，由临时设备端 DEX 工具将当前用户的
  原生 Drawable 渲染为 96×96 PNG，兼容自适应与矢量资源；Qt 图像对象只在主线程创建。
  缓存归当前设备页面所有，切换视图复用缓存，刷新列表使旧缓存和在途结果失效。
  离线、切走页面或关闭时停止追加任务，关闭沿用 worker 等待屏障。
  读取失败保留占位图标，悬停提示刷新重试，不将读取失败视为成功。工具只推送至随机临时路径，
  本批结束、失败或取消时尝试删除该文件，清理失败会回报失败；每条命令有超时，取消在当前命令结束后生效。
  设备端另设 15 秒退出保护，即使 PackageManager 或图标绘制卡住也不会持续留在后台。
- **失败与清理**：输入或目标校验失败时不启动 worker；worker 在开始前收到中止请求就不执行设备
  操作。备份先写 staging，恢复安装失败不会报告成功；晚到或错代批次结果直接丢弃。高影响动作
  当前不二次确认，安全边界依赖目标校验和真实失败传播。
  应用重启只有在 force-stop 成功后才执行启动；停止失败保留原因并终止后续操作。

## 4. Monkey、截图、录屏与诊断

- **Monkey**：位于截图与诊断页。点击“获取包信息”只读查询；点击开始先保存所选设备、包名和
  参数快照，再在既有 worker 中逐台读取安装路径和包元数据，单条命令超时为 5 秒。包名为空时识别
  各设备前台应用；无法识别或包名不一致时要求明确填写。同包版本不同可继续并逐台展示版本。
  只有全部结果完整且输入仍匹配时才启动原 Monkey 批次；失败、取消、目标或输入变化、关闭及晚到结果
  均不能启动旧请求。取消在每条查询前后检查，当前命令结束后释放后台执行。启动后继续跟踪进程和
  前台包；用户中止或连续探测失败会停止进程并清理日志资源，未知前台状态不按成功处理。
  每台设备在任务排队前登记批次，排队期间停止后不再启动进程；启动、停止和收尾校验同一批次归属，
  晚到的旧批次停止不会影响新批次。停止入口沿用启动时保存的设备，清空或更改当前选择不会重定向停止操作。
- **截图**：每批请求按 operation/task 隔离，校验目标、路径和 PNG artifact 后汇总。成功结果后台
  追加到 ScreenshotPage；不在该页时只显示“查看结果”提示，不抢占导航。取消会原子标记未完成
  unit，晚到回调被丢弃。
- **录屏与诊断**：录屏按批次管理启动、停止和拉取；本地视频拉取成功但远端清理失败时保留文件并
  单独报告清理错误。bugreport 解压使用安全 ZIP 边界。
  录屏 model 在进程创建前校验时长、码率和成对的宽高参数，非法数值不会进入设备 shell。

## 5. Live Logcat

- **触发**：从左栏“实时 Logcat”为一台设备打开日志会话，可选择包过滤。
- **主流程**：worker 消费单一 logcat 流并在 producer 侧批量；包过滤周期刷新全部 PID，只发布
  当前 generation 的匹配行。切走页面暂停绘制但继续消费。
- **界面**：嵌入时只保留工作区标题；中文过滤工具、采集控制和状态分层显示，工具条按宽度换行。
  日志使用独立主题背景和等级颜色；正在阅读历史时追加不会拉回底部，回到底部后恢复跟随。
  “停止采集”保留当前会话和内容；顶部“关闭日志会话”释放该会话。
- **失败与清理**：包未运行或 PID 查询失败时 fail-closed 并重试，不退化为其他应用日志。显式
  关闭会话或应用关闭才停止进程、reader 和 PID 刷新线程；资源归零前页面保持释放屏障。

## 6. 文件浏览与传输

- **触发**：从 Devices 打开固定设备的 File Explorer，执行浏览、pull/push、编辑、复制、移动、
  删除、chmod、APK 安装或脚本操作。
- **主流程**：服务层校验名称和路径；短命令走 CommandRunner，传输走 ProcessRunner；成功后刷新
  目录。切走页面保留路径、预览和仍需继续的任务。
  嵌入页仅保留工作区标题；文件类型列显示图标，悬停和辅助信息保留完整类型，排序和目录进入行为不变。
- **失败与清理**：未选设备显示空态，离线会话禁止新操作；非法名称、.. 和失败结果不会进入
  成功刷新。显式关闭会话中止 worker，尚未进入执行体的任务不会启动。
  文件列表解析保留名称中的连续空白和尾部空白，不把合法文件名中的错误关键词当作命令诊断。

## 7. Remote

- **触发**：在左侧进入远程控制，同页使用屏幕镜像或按键手势，为会话选定一台设备后启动 scrcpy。
- **主流程**：Remote 使用独立于全局批量复选的会话设备；多候选且无当前会话时先显式选择。
  预检后生成 LaunchPlan，ProcessRunner 启动 scrcpy；stderr/FPS reader 和 watchdog 更新状态，输入只
  发送给该会话设备的持久 ADB shell。已启动的 Remote 运行保持绑定原会话设备，不被后续候选刷新改向。
- **失败与清理**：无会话设备、离线会话、预检或前置设置失败都拒绝后续动作。关闭时先停止输入
  准入，再等待 executor 和 warmup producer，最后关闭持久输入会话；非 Windows 缺少 PATH scrcpy
  时明确失败。

## 8. MobilePerf

- **触发**：在 System/Performance 选择设备和包，配置采样后启动。
- **主流程**：页面生成运行配置，Runner 创建独立临时目录和子进程，双管道 reader 排空输出；
  只有退出码成功且本次生成非空报告时才显示完成。切走页面不停止采集。
- **失败与清理**：启动失败立即恢复 UI；停止先写 stop 标记并等待报告，超时后强制停止。旧报告、
  空报告或非零退出不能伪装为成功。
  停止调用返回时若进程仍存活，保留采集会话与配置锁定并允许重试停止；应用关闭同时等待
  停止线程和采集进程，未退出资源保持明确的超时状态。

## 9. 任务中心

- **活动项**：只来自 OperationManager 当前快照，不代表 Monkey、录屏、MobilePerf 等全部后台工作。
- **历史项**：MainFrame 当前把兼容 operation_completed 信号写入进程内有界 TaskHistoryStore；
  应用重启后清空。
- **取消**：按钮总是调用 OperationManager.request_cancel()；MainFrame 当前只为安装批次和截图
  追加资源停止路由，其他任务是否真正停止取决于其自身执行边界。

- **运行记录**：原独立操作日志页已移除。任务中心的可展开区域复用唯一 LogPanel 和 LogService，
  保留级别筛选、清空显示与有界历史；折叠、切页不丢弃后台操作结果，不删除用户磁盘日志。
  从顶部“更多”查询设备信息时，先打开任务中心并展开运行记录，再发起原信息请求；异步返回不抢占后续导航。

## 10. 页面会话与应用关闭

- 工作区内部功能导航切换概览分类时复用同一面板内容；切换深层功能只调用功能页 deactivate()，
  同一 feature/device/generation 返回时复用页面。用户
  显式关闭才执行 request_dispose()；旧代次在 worker 或进程归零前不能重激活。
- 应用关闭先封闭新任务准入，再并发广播扫描、各业务主页面、面板和 Controller 停止，并在共享
  deadline 内后台等待。单个资源登记失败不会跳过其他资源。
- finalizer 记录仍未退出的 residual、保存配置并完成窗口关闭；超时不被描述为资源已归零。
  瞬态消息/输入/短表单只结束该次交互，不创建长期页面会话。
