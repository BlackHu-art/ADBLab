# 操作反馈、任务记录与专用结果

普通功能页不设置通用执行步骤、操作历史或结果面板。完整过程、逐台正文和失败详情集中在
任务中心“本次操作”；右上角 Toast 提供即时反馈。应用不再提供全局日志看板及清空看板
快捷键。Monkey 和性能采集的跨会话报告仍在“测试结果”。

## 通知规则

| 级别 | 颜色 | 使用场景 |
| --- | --- | --- |
| 信息 | 蓝色 | 执行中、取消、一般说明 |
| 成功 | 绿色 | 操作全部成功、文件导出完成 |
| 注意 | 黄色 | 部分设备失败、需要检查输入或条件 |
| 错误 | 红色 | 操作失败 |

超过 500 ms 仍未完成的通用操作显示执行中提示。完成提示替换同一请求的进行中提示；
窗口最多同时显示三条通知。通知不抢焦点、不自动切页，可关闭、悬停暂停倒计时，并通过
“查看任务”定位当次请求。文件选择器取消且未提交任务时不弹完成提示。重复启动同一在途
操作只提示查看原任务，不重复执行。独立页面的高频过程说明仅记录，明确结果级别才通知。

## 功能归属清单

通用信号注册表为 [action_catalog.py](../../controllers/action_catalog.py)。新增入口必须
声明归属；接线遗漏会失败，回归测试遍历全部已声明信号。

| 页面 | 本页交互与反馈 | 完整记录 |
| --- | --- | --- |
| 设备概览、设置 / ADB 维护 | 原设备状态与信息卡更新，操作终态 Toast | 任务中心 |
| 应用工具 | 包名按原准入规则回填；安装、卸载、清数据等终态 Toast | 任务中心 |
| Monkey | 紧凑目标摘要、参数、启动/停止及业务运行状态；终态 Toast | 任务中心及测试结果 |
| 截图与屏幕 | 图片直接进入相册；录屏与输入终态 Toast | 任务中心及产物入口 |
| Shell、广播、Activity、链接、Android 设置 | 终态 Toast；查询正文通过“查看任务”阅读 | 任务中心 |
| 重启、连接模式、端口、服务开关、电池、输入法、模拟器、系统诊断工具 | 终态 Toast；列表与命令返回通过“查看任务”阅读 | 任务中心 |
| 应用管理 | 列表与详情按原请求代次更新；显式终态 Toast；无本地记录区 | 按设备汇集到任务中心 |
| 文件管理 | 目录、文件预览与传输进度保留；文件变更和传输结果 Toast | 任务中心 |
| 远程控制 | 会话、队列与停止入口保留；完成、错误及注意 Toast | 按设备汇集到任务中心 |
| 实时 Logcat、性能采集 | 保留实时采集内容、过滤、指标与报告 | 原采集与归档链路 |

实时 Logcat 和性能采集输出是其业务内容，与已移除的全局日志看板无依赖。

## 报告与日志

Bugreport、ANR、设备日志提取在生成文件后显示紧凑的“已生成文件”入口，可选择文件、打开
文件或定位文件夹，最多保留最近 20 个文件。重复快照不重复添加。清理日志只发送通知，不
产生空白结果区。执行进度、失败原因及逐台明细仍在任务中心。

## 性能诊断

内存、CPU 负载、电池、运行时长、进程快照、GFX、唤醒锁与网络统计共享专用数据阅读器。
只显示查询名、时间、设备结果选择与正文，支持完整内容搜索、复制和导出。没有步骤列表或
本地操作历史下拉框。新的查询结果替换上一次；晚到的旧查询不能覆盖新查询，旧结果仍可在
任务中心查看。

正文最多向 Qt 文档加载 64,000 字符；搜索基于完整返回并展示匹配附近内容，复制、导出保留
完整正文。文件动作复用串行后台队列，只有原子写入成功后才通知完成。打开失败、文件缺失
或权限不足按错误反馈。通知遮蔽设备标识和不必要的本机路径；任务正文替换本次设备标识，
采集附件本身不会被改写。

## 统一操作设备入口

需要设备上下文的功能页均使用右上角设备按钮：批量功能显示“操作设备 · N 台”，单设备
会话显示“当前设备 · 设备序号及名称”，并注明离线或未勾选状态。弹层统一使用设备列表，
应用管理、文件管理和实时 Logcat 只允许单选；远程控制、性能采集与其他批量功能支持多选、全选和清空。
设备序号在本次应用运行内固定，不随发现列表排序、离线重连或选中子集重新编号；设备概览、
选择弹层、Monkey 包信息、采集状态、任务结果和产物入口使用相同的显示归属。真实身份只用于
内部路由；任务名称在提交时冻结，旧记录不随后来勾选或名称更新变化。

单选页面勾选一行时，统一提交该设备为操作目标并切换对应会话，不再要求额外勾选操作资格。
取消选择保留缓存内容和停止入口；切页本身不裁剪共享目标。性能页通过下方会话列表切换当前
查看设备，勾选多台不自动批量启动采集。设备下线、运行锁定、关闭中的状态仍由原宿主投影，
弹层不接管会话生命周期。已运行任务始终使用提交时设备。可关闭页面在按钮旁保留关闭入口。

| 操作范围 | 交互规则 |
| --- | --- |
| 应用工具、报告与日志、诊断、截图录屏、Shell、系统批量功能 | 使用提交时已选设备快照；完成通知按设备汇总成功、失败和未完成数量，同一设备多个命令只计一次 |
| 文件管理、应用管理、实时 Logcat | 下拉单选并同步切换操作会话；旧会话缓存保留，清空选择后拒绝新操作 |
| 远程控制 | 镜像按启动时全部已选在线设备创建独立进程；按键和手势广播到点击时全部目标；停止与清理保持原批次归属 |
| 性能采集 | 下拉多选并保留逐设备会话；会话列表选择当前查看与配置的设备，启动和停止仍作用于该会话 |
| 获取当前应用并回填唯一包名输入框 | 只允许选择一台设备，避免返回互相覆盖；Monkey 的多设备包信息核对使用独立准备流程 |
| 新建正向端口转发、按 PID 结束进程 | 只允许选择一台设备，按钮说明原因且提交时再次校验；反向映射继续支持多设备 |
| 查询或移除正向转发 | 按设备精确过滤本机规则，逐条删除所选设备的映射；新建使用 `--no-rebind`，已占用端口需先处理原规则 |
| 停止、取消、任务清理 | 保持原任务设备和批次；取消勾选、设备离线或切换页面不会改向新设备 |

正向转发监听端口由本机 ADB server 共享，`forward --list` / `--remove-all` 是全局范围，
不能靠 `-s` 将全部删除缩小到某台设备；反向映射位于设备端。命令语义参见
[ADB 官方手册](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/user/adb.1.md)。

## 状态与资源边界

- 请求、异步任务、返回载荷与 Operation 单元保持稳定身份。全部已登记命令及续发命令返回
  后才结束；成功文案不等于任务完成。原执行器继续负责资源、取消与停止。
- `ActionFeedbackPresenter` 把所有快照送入任务中心，并驱动 Toast、报告文件入口与诊断阅读器。
  `ActionResults` 保留最近 80 个已结束请求；阅读器保留最近 20 个已结束结果，保护在途及
  当前阅读项。普通结果不跨重启保存，重要内容需主动导出。
- 独立页面记录按来源与设备汇集，最多 200 条、每条 64,000 字符；级别来自明确参数，不解析
  日志文案推断成功。关闭后的消息不能创建通知或复活任务。
- `LogService` 保留开发诊断与线程缓冲；警告/错误摘要进入 `DiagnosticJournal` 和设置页，
  后台保存当前会话最近 200 条摘要，每条最多 2,048 字符。正常业务正文不进入诊断文件。
  DEBUG 的源码 stderr 策略不变。退出时现有 finalizer 排空文件队列。
- “输出文本字号”兼容 `log_font_size`；`log_max_lines` 作为原性能采集输出兼容配置保留。
  主题、配置 schema、设备历史和采集格式不变。

## 维护验证

`test_action_results.py` 覆盖任务身份、部分失败、续发、异常、取消及晚到回调；
`test_action_feedback.py` 遍历通用入口并检查任务记录、通知与导航；通知、设备弹层及全局
状态分别由 `test_notifications.py`、`test_device_context_bar_presentation.py` 和
`test_global_device_context.py` 覆盖。业务列表、采集、相册和关闭行为沿用关联测试。
`test_multi_device_network.py` 覆盖端口归属、冲突保护、部分删除失败和多设备 PID 拒绝；
`test_monkey_preparation.py`、`test_performance_sessions.py` 覆盖多设备准备、独立采集和原目标停止。

自动化使用合成设备和受控返回，不操作真实设备的应用、系统开关或文件。实机验收需要指定
测试设备，检查成功、设备中途离线、取消、权限不足和生成文件被移动的情况。
