# 操作反馈、任务记录与专用结果

普通功能页不设置通用执行步骤、操作历史或结果面板。完整过程、逐台正文和失败详情集中在
任务中心的统一列表；主窗口共享右侧任务抽屉提供即时反馈。应用没有全局日志看板及清空看板快捷键。
任务中心沿用与性能会话、测试结果一致的 Fluent 表格样式展示本次与归档记录。
普通操作标记“本次”，Monkey 和性能采集报告标记“已归档”；保留搜索和任务类型筛选。
状态、进度与异常未读标记在记录行中展示，不再提供状态切换或状态下拉；活动与未读计数
使用未筛选投影。窄窗可横向滚动查看全部列，点击任务或使用键盘打开同一个共享阅读器。
主窗口点击任务名或记录行、使用键盘进入任务，从右侧打开同一个阅读器；正文、参数与有内容的生成文件直接可读，
无需展开；复制、导出和附件动作仍在各自内容附近。长正文的预览与全文能力仍遵守下文预算。
后台更新不抢占正在阅读的请求；显式定位可清除阻挡目标的筛选，不重新执行命令或改向设备。
异常待查看标记只属于本次会话的阅读状态，不改变业务结果或持久化数据。
持久化与附件保留规则见
[DATA_FLOW](../project-knowledge/DATA_FLOW.md#测试结果与方案)。

## 通知规则

| 级别 | 图标颜色 | 使用场景 |
| --- | --- | --- |
| 信息 | 当前强调色 | 执行中、取消、一般说明 |
| 成功 | 绿色 | 操作全部成功、文件导出完成 |
| 注意 | 黄色 | 部分设备失败、需要检查输入或条件 |
| 错误 | 红色 | 操作失败 |

仅已确认的终态失败可自动展开抽屉，包括逐项失败和已确认的请求级收尾失败。执行中、成功、
取消及一般注意只更新记录和导航状态；截图成功仍直接更新相册，不打开抽屉。
会话说明仅最新一条明确失败且请求通知时可自动呈现，历史失败不会因后续成功或说明重新弹出。
自动呈现不抢占另一个正在阅读的任务，也不把自动可见当作用户已经查看。
收起抽屉不取消任务；同请求晚到结果不会把已收起的抽屉重新打开。
重复启动同一在途操作不重复执行，也不自动打开原请求；记录始终可手动查看。
独立页面的高频过程说明仅记录。
结果摘要按设备显示非零成功、失败和未完成数量，请求级收尾失败不冒充全部设备成功。
完整正文、文件和导出入口复用原阅读器，不依赖技术日志。
抽屉只有零个或一个返回条目时不显示结果选择框；本机操作不重复显示“本机”目标。
条目与请求的目标或状态不同，则显示必要的只读说明。设备名称包括兼容结果的
`target_names`，不能因收紧布局丢失。两个及以上独立条目保留按原任务身份切换的入口，
同一设备的多条命令也可分别查看；尚未返回的设备继续明确标为运行中或结果不完整。
请求说明与标题或所选条目正文完全相同时只展示一次；已知成功 Shell 格式的完整输出与
当前正文精确一致时仅展示命令，原说明仍可通过提示或辅助技术读取。错误、附加信息和
不确定格式保留原说明，不按文案猜测业务结果。
独立、诊断及行内阅读器默认呈现不变。持续会话的目标由抽屉元数据展示一次，后备正文与
来源提示相同时只保留提示，已有会话正文继续可读。

抽屉以不透明主题表面覆盖主内容右侧，只移动位置，不挤压、淡出或重建正文。
默认宽度为 390 逻辑像素，约 280 ms 展开与收起；快速反向从当前位置继续。
在任务中心选择历史记录和筛选任务；侧边只显示当前任务，状态提示说明其保留期限。
显式查看可把焦点交给关闭入口，自动反馈不抢焦点；Esc 收起后归还仍有效的原入口。
关闭立即退出鼠标和 Tab 链，最后一个动画帧结束后才解除阅读保护。
主窗外侧首击只收起，下一次普通点击可立即操作；完整手势、弹出菜单与窗口管理的边界见
[UI 实现](../project-knowledge/UI_IMPLEMENTATION.md#1-主窗口与页面组合)。

任务中心导航入口以活动任务为最高优先级，显示活动数量和强调色环，并用黄色点提示未读异常。
忙碌投影仅决定环是否旋转；稳定运行的持续会话仍计入活动数并保留停止入口。镜像就绪不会产生
完成事件，忙碌变化也不构成新的异常已读版本。
没有活动任务时显示未读异常；明确观察到实时活动转为成功且无更高优先状态时，短暂显示
3000 ms 成功反馈。历史载入、说明、重复终态或任务消失均不触发成功；新活动、异常和隐藏
会丢弃旧成功提示。查看异常只清除当时异常版本的未读，记录的业务结果保持不变。

投屏、实时 Logcat、性能采集以“持续会话”进入同一列表。活动状态来自原 owner 的资源义务，
启动、停止、清理和结果收尾均不提前归零；停止失败仍可保持活动并提示异常。会话的“停止会话”
按钮验证原 owner 与运行版本后沿用原停止入口，不受当前勾选影响；完整流式内容返回来源页查看。
主动停止镜像后，等镜像进程及其子进程释放再标记为已停止；这时的非零退出码只写入诊断。
未经请求的非零退出仍报告失败。

应用诊断、文件导出等非任务提示继续使用现有 Toast。脱离主窗口使用的独立页面保留原通知回退，
独立任务组件默认保留行内阅读兼容模式；主应用统一采用外部共享抽屉。

## 报告与日志

Bugreport、ANR、设备日志提取在生成文件后显示紧凑的“已生成文件”入口，可选择文件、打开
文件或定位文件夹，最多保留最近 20 个文件。重复快照不重复添加。清理日志只发送通知，不
产生空白结果区。执行进度、失败原因及逐台明细仍在任务中心。
文件选择框随面板宽度省略过长文案，悬停可查看完整的脱敏名称；省略显示不改变打开目标，
已有长文件名也适用。

## 性能诊断

内存、CPU 负载、电池、运行时长、进程快照、GFX、唤醒锁与网络统计共享专用数据阅读器。
只显示查询名、时间、设备结果选择与正文，支持完整内容搜索、复制和导出。没有步骤列表或
本地操作历史下拉框。新的查询结果替换上一次；晚到的旧查询不能覆盖新查询，旧结果仍可在
任务中心查看。
长设备名称在选择框中省略显示并保留完整提示；新结果自动定位只调整纵向位置，不横向移动
整个功能页。窗口和字号变化不截断可复制、导出的完整正文。

正文最多向 Qt 文档加载 64,000 字符；搜索基于完整返回并展示匹配附近内容，复制、导出保留
完整正文。文件动作复用串行后台队列，只有原子写入成功后才通知完成。打开失败、文件缺失
或权限不足按错误反馈。通知遮蔽设备标识和不必要的本机路径；任务正文替换本次设备标识，
采集附件本身不会被改写。

## 统一操作设备入口

应用管理、文件管理、实时 Logcat、远程控制、性能采集、应用与诊断、截图与屏幕及系统工具使用
右上角设备按钮；首页、设备概览、任务中心和设置不新增此入口。设备概览仍在本页提供选择、
连接与刷新。批量功能显示“操作设备 · N 台”，单设备会话优先显示型号，缺失时使用安全名称，不带
“设备 1/2”等编号前缀，并注明离线或未勾选状态。点击按钮在页头下方展开透明设备列表，将
正文平滑向下推开；按钮立即进入 checked 状态并显示“收起设备”，箭头随展开过渡旋转。
列表内容保持自然行高，透明外层平缓起步、逐步露出；连续点击从当前位置反向，不重复创建列表。
同一设备摘要下，按钮展开与收起保持相同宽度。键盘提前进入列表时完成展开以保证焦点可见；
收起期间立即退出列表焦点链并停止接受行操作，同时保持原有行外观，不将整列切成禁用灰色。
展开入口、全选、清空及行内操作统一沿用无常驻背景的透明按钮样式。
这些按钮与设备复选框仅在键盘导航时显示焦点外框，鼠标点击不显示蓝色外框；
设备连接面板的动作和历史地址行采用同一规则。主题、强调色及字体设置即时生效，
焦点切换不改变控件尺寸和文字位置。
再次点击或在选择区内按 Esc 平滑收起，结束后不占位置；按钮立即恢复原设备摘要。
切换页面、功能、窗口隐藏或开始关闭时立即结束过渡并收起；点击正文和同功能内切换设备不会收起。

每台设备只占一行，依次显示复选框、品牌、型号、Android 版本和连接方式（USB、无线或
模拟器）。品牌、型号、Android 版本和连接方式共用列宽，上下对齐；各列按当前列表最长内容
计算宽度并设上限，窄窗同步省略。弹性留白只在左侧信息组与右侧必要短状态、本页原有会话
操作之间。部分设备缺品牌时保留同列空位，全部缺失时隐藏品牌列及对应分隔线；型号缺失时
使用安全名称，不以真实连接标识补齐。名称不带编号前缀；字段间使用纵向分隔线，设备行之间
使用横向分隔线。
数据来自既有缓存，不为展示新增 ADB 查询或详细任务状态采集。
选中状态仅由复选框表达，不显示蓝色行框；保留中性 hover 和键盘焦点反馈。窄窗省略单行字段，
并将已有操作改为同动作的图标按钮，完整信息通过悬停提示及可访问说明提供，不增加横向滚动。
列表固定预留五行高度，少于五台（包括空列表）也保留该空间，超过五行在展开区内部滚动；
极短窗口仍以可用正文高度的 45% 为展开区上限，优先保留正文空间，字号变化按实际行高计算。
应用管理、文件管理和实时 Logcat 只允许单选；其余上述功能支持多选。全选、清空选择位于
列表顶部同一行，单选页隐藏全选；截图页的“清除截图结果”也在此行，不归属于某一台设备。
设备概览卡片头部固定单行：左侧按“品牌 · 型号”紧凑排列（有效名称或别名仍优先于型号），
右侧按“连接状态 · 电量”排列；不添加“设备 N”前缀。品牌或电池信息缺失时隐藏对应字段
及分隔符，名称缺失时使用安全回退文案。窄窗口和大字号下右侧优先展示在线状态与电量数值，
其他长文本单行省略；悬停提示、辅助说明和复制详情仍保留完整内容。
设备序号在本次应用运行内固定，不随发现列表排序、离线重连或选中子集重新编号；Monkey
包信息、采集状态、任务结果和产物入口继续使用全局稳定编号及原名称规则。真实 ADB 连接标识、
会话键和持久化格式不变；任务名称在提交时冻结，旧记录不随后来勾选或名称更新变化。

单选页面勾选一行时，统一提交该设备为操作目标并切换对应会话，不再要求额外勾选操作资格。
取消选择保留缓存内容和停止入口；切页本身不裁剪共享目标。性能页通过下方会话列表切换当前
查看设备，勾选多台不自动批量启动采集。设备下线、运行锁定、关闭中的状态仍由原宿主投影，
选择区不接管会话生命周期。已运行任务始终使用提交时设备。“关闭文件管理”“关闭应用管理”
及“关闭日志会话”只显示在当前会话的设备行右侧；该设备离线后，保留不可勾选的当前会话行
和原关闭入口，不扩展为历史会话列表。点击关闭按钮不会切换或勾选设备；关闭中显示“正在关闭”
并禁用重复提交，宿主释放完成后收起选择区。关闭只影响当前功能会话，不取消设备勾选或断开
ADB 连接；日志页内的“停止采集”则保留会话和日志供查看。“清除截图结果”只释放图库会话，
不删除本地图片；实际文件删除由图库的单张删除和“删除全部”执行。
远程控制页的设备列表同时投影已有镜像的单台状态与停止/重试，按钮绑定原设备，点击不改变勾选。
仍有资源的离线镜像保留停止入口；未勾选的设备不可重试。准备和全停期间锁定本页勾选、全选及清空，
状态退出后恢复；其他页面不继承这份锁定。镜像的启动、追加及停止全部保留在正文顶部操作栏，
取消勾选不停止已有镜像。采集和录屏的其他操作继续留在对应正文。顶部设备按钮保留设备图标和展开箭头。

正向转发监听端口由本机 ADB server 共享，`forward --list` / `--remove-all` 是全局范围，
不能靠 `-s` 将全部删除缩小到某台设备；反向映射位于设备端。命令语义参见
[ADB 官方手册](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/user/adb.1.md)。

## 状态与资源边界

- `ActionJob` 固定通用请求及命令身份，`ActionEnvelope` 随原异步返回传递；已接入 Operation 的
  命令同时保留 `OperationMetadata`，并以校验后的业务单元终态归并结果。
  `ActionResult.operation_ids` 在命令入队前关联已校验的 Operation 身份，任务表据此合并进度与结果；
  无关联的来源各自保留，不能凭标题、设备或时间推测为同一任务。全部已登记命令及
  续发命令返回后才结束；成功文案不等于任务完成。原执行器继续负责资源、取消与停止。
- `ActionFeedbackPresenter` 订阅 `action_result_changed`，把快照送入任务中心和共享抽屉，
  并更新报告文件入口与诊断阅读器。主窗口的通用正文来自 `ActionResults`，`TaskHistoryStore` 只保留
  兼容终态历史入口，不能把旧 `operation_completed` 信号当作完整正文和请求身份的来源。
  `ActionResults` 对已结束请求设置 80 条和 32 MiB 正文预算；阅读器设置 20 条和 16 MiB
  正文预算，任一超限时按完成先后移除较早的已结束历史，独立页面记录按最近更新排序；不以
  提交时间或系统时钟判断完成先后。前者保护最新完成请求，后者保护当前阅读项，
  两者都保护在途请求；任务中心还保护刚收到的最新结果，避免尚未来得及打开即被正文预算淘汰。
  因此受保护内容可以暂时超过预算；该预算按 Python 字符串占用估算，
  不是应用总内存上限。保留结果不截断全文，仍可完整搜索、复制和导出。
  诊断阅读器接受旧查询的终态以释放在途保护，但不让它覆盖当前新查询。
  普通结果不跨重启保存，重要内容需主动导出。
- 独立页面记录按来源与设备汇集，每组最多 200 条说明、每条 64,000 字符；整组仍参与上面的
  请求数与正文容量淘汰。级别来自明确参数，不解析
  日志文案推断成功。关闭后的消息不能创建通知或复活任务。
- `LogService` 保留开发诊断与线程缓冲；警告/错误摘要进入 `DiagnosticJournal` 和设置页，
  每条最多 2,048 字符。环境检测的专用入口也保留 INFO 能力及耗时诊断，与警告/错误共用
  当前会话最近 200 条容量；后台原子保存到用户数据目录的 `logs/application-diagnostics.log`。
  INFO 不计入设置页的异常计数，也不触发异常 Toast。正常业务正文不进入诊断文件。
  ADB 能力探测失败摘要区分连接、发送、读取状态、长度及正文阶段，并保留尝试次数、总预算、
  阶段与总耗时、固定错误类别和系统错误码。摘要不包含请求参数、设备标识或响应原文；取消
  轮询中的暂时超时不记为故障。诊断复用 Qt 主线程投递及后台保存，打包模式也可导出；成功的
  常规健康检查不逐条写入，避免挤占失败、恢复和显式重检记录。
  队列合并尚未执行的重复诊断写入，仅保留最新快照；后台检查附件后回到 GUI 线程调用系统关联
  程序。退出时先在 GUI 线程刷新并冻结日志，再由 finalizer 排空文件队列。诊断保存失败会进入
  最终收尾失败结果，手动导出或打开失败则由对应动作提示。旧 `LogService.log()` 调用
  无需迁移，各级别在源码开发控制台显示一次脱敏摘要；DEBUG/INFO/SUCCESS 进入 stdout，
  WARNING/ERROR/CRITICAL 进入 stderr；慢命令只记录固定类别、耗时、退出码和输出长度，
  不记录动态命令 token；诊断脱敏覆盖认证方案与带空格的引号凭据。详见
  [日志架构](../project-knowledge/ARCHITECTURE.md#主题字体与日志)。
- “输出文本字号”兼容 `log_font_size`；`log_max_lines` 沿用旧键名，仍是性能采集文本缓冲的上限。
  主题、配置 schema、设备历史和采集格式不变。

## 维护验证

`test_action_results.py` 覆盖任务身份、部分失败、续发、异常、取消及晚到回调；
`test_action_feedback.py` 遍历通用入口并检查任务记录、通知与导航；通知由
`test_notifications.py` 覆盖，页内设备列表、兼容连接弹层及全局状态由
`test_inline_device_selector.py`、`test_device_context_bar_presentation.py` 和
`test_global_device_context.py` 覆盖。业务列表、采集、相册和关闭行为沿用关联测试。
`test_multi_device_network.py` 覆盖端口归属、冲突保护、部分删除失败和多设备 PID 拒绝；
`test_monkey_preparation.py`、`test_performance_sessions.py` 覆盖多设备准备、独立采集和原目标停止。
`test_diagnostics.py` 覆盖异常摘要边界、原子导出失败保留原文件和关闭前最后一条诊断；
`test_run_library_integration.py` 覆盖终态归档、写入排空及失败后继续保存其他状态。

自动化使用合成设备和受控返回，不操作真实设备的应用、系统开关或文件。实机验收需要指定
测试设备，检查成功、设备中途离线、取消、权限不足和生成文件被移动的情况。
