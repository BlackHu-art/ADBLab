## 范围和结果

用户要求合并屏幕镜像与按键手势、归并系统和应用分页、改造性能采集样式，修复截图中的应用行
可读性，并将支持多选的设备入口放到所有页面，同时迁移和重做旧连接页。

- 保留七个物理主页面，将业务区的可见功能入口整理为 11 个，旧入口保留 5 个兼容别名。
- 全页常驻设备栏负责多选、连接、刷新、详情与断开；固定设备功能在同一区域显示“当前查看”
  及会话关闭，操作目标集合与已有单设备会话分别处理。
- 旧连接页成为设备概览；批量安装移入应用操作，普通重启复用设备配置的 System 模式，重启
  ADB 位于设置维护卡。原状态源、信号及设备目标校验继续复用。
- App Manager 修复浅深主题交替行、复选列、字号与表头、列表最小视口及长状态句撑宽问题，
  嵌入时收起重复标题。500px / 22pt 外层横向滚动范围从 47 降为 0。
- Performance 分为运行、配置和结果卡，保留单滚动区和原采集生命周期；图表及日志跟随主题与字号。
- Settings 卡片按字号和可用宽度重排，保留控件、配置值、信号和恢复默认行为；系统输入框
  使用稳定用途样本和 Qt 净宽测量，避免端口、短信、电话及经纬度提示被固定宽度裁切。
- 分类布局只测量当前页，避免隐藏长应用页撑大 Monkey 页；720px / 22pt 页尾范围从 1720 降为 573。
- 全局弹层明确向下展开；隐藏 SidePanel 归属于 MainFrame，随主窗销毁并断开全局样式连接。

沿用 Python 3.11、PySide6 与现有 Fluent 依赖，参考本地 Gallery 的卡片、工具栏和设置组。
本轮未改变生产依赖版本、配置 schema、应用版本或发布流程，未提交或暂存工作树修改。
