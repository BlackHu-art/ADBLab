# Remote 投屏侧栏实施计划

> 用户已确认在当前工作区实现；本文记录本轮边界，不替代现状文档。

**目标：** 主窗口保留参数和会话管理；Windows 投屏旁显示绑定单一会话的侧栏；完整遥控器独立打开。

**实施与验证：**

1. 新增原生窗口适配器：按进程归属和精确标题绑定，使用物理坐标跟随，不激活窗口；验证子进程、错误归属、句柄失效、最小化。
2. 新增侧栏控件：六个常用操作、更多操作和折叠；验证全部 23 个动作只发送一次、禁用及弹层清理。
3. 新增会话输入准入：固定设备与会话代次，选择变化不改向，停止、离线、替换和关闭撤销请求；验证现有广播输入保持原义。
4. 接入 GUI 生命周期并移动完整遥控器：主页面保持现有参数和会话；验证移动、缩放、边缘回退、最小化恢复、关闭、重试与独立窗口销毁。
5. 运行直接和关联 Remote/设备上下文测试、修改文件静态检查；使用合成外部窗口验证 Windows 原生行为。真实设备投屏、冻结产物和混合 DPI 多屏分别报告验证边界。

**文件与接口协调：**

| 任务 | 生产者 / 消费者 | 约定 |
| --- | --- | --- |
| 原生适配 / 跟随控制器 | WindowsWindowTracker / RemotePanelDock | snapshot 返回物理矩形、工作区、DPI 和显隐状态；绑定失效后不换目标 |
| 侧栏 / 跟随控制器 | RemoteToolbar / RemotePanelDock | key_requested、action_requested、layout_changed；隐藏时关闭更多弹层 |
| 输入 / 跟随控制器 | RemotePanelInput / RemotePanelDock | 指令带原会话；失效用 Event 撤销；独立遥控器仍用原广播路径 |
| 主窗 / 输入 | MainFrame / RemotePanel | 在线快照与当前选择分开传入，发现不可用时停止接纳输入 |
| 表单 / 独立窗口 | RemotePanelForm / RemotePanelDock | 复用现有完整按键区、主题和响应式绑定，不复制协议映射 |

**实施决定：** 使用 GUI QTimer 查询少量 Win32 状态，等待窗口期间节流枚举；不新增后台线程、依赖或改变 scrcpy 渲染方式。非 Windows 保留独立遥控器入口。当前脏工作树和既有测试覆盖保留，旧布局断言迁到对应新容器。
