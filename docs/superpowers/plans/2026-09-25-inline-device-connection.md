## 验收约束

- 默认收起且不占布局空间；保留设备摘要原文、连接按钮、刷新图标和原设备卡片。
- 将“断开所选设备”移到工具栏，显示“断开”，提示说明作用于已选设备。
- 点击“连接设备”展开或收起；展开默认扫码，仅显示“扫码 / 配对码 / IP 连接”三页签，无附加标题。
- 使用透明背景继承现有材质；三个页签按当前宽度和字号共享所需高度，紧凑排列。
- 扫码说明与二维码并列；配对地址、配对码和提交横排；IP 输入与连接横排，历史置于右侧。窄窗自然换行。
- 最近连接独立显示名称、地址；点击只填入，显式点击连接才提交。
- 收起和离开设备概览立即隐藏并清除秘密，取消当前会话；等待资源屏障后才允许再次启动。禁止隐藏二维码确认和晚到回调重启。
