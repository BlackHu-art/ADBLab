# 操作设备页内展开选择器实施方案

> 状态：首版及第二轮调整已实施；第三轮调整品牌、型号展示及概览标题，验证待本轮收口。第二轮完成组件、关联会话和缩放验证；真实设备及 DWM 云母外观仍需实际窗口验收。首版以 `24a62ea` 为起点，分轮验证记录见文末。
>
> 第二轮明确固定五行、展示版本和连接方式、局部省略编号、仅用复选框表达选中，以及展开按钮状态。仍不采用双行信息、详细任务标签或新增状态汇总区。修改保留在当前 `ui-redesign` 工作区，未提交。
>
> 第三轮按用户要求拆分品牌与型号，信息组按文本宽度紧凑左排；概览取消编号前缀，型号作为标题、品牌独立展示。任务名称与编号、内部设备路由和持久化边界不变。

**Goal:** 把现有操作设备浮层替换为紧凑的页内展开列表，保持设备选择、会话和任务归属不变。

**Architecture:** 复用唯一 DeviceContextBar 及其 DevicePicker，将选择内容嵌入页头下方；操作目标仍提交到原 SidePanel / DeviceManager，按钮仍调用原宿主动作。

**Tech Stack:** Python 3.11、PySide6、当前 qfluentwidgets；沿用主题、云母、字体及图标，无新增依赖。

**Spec:** 以下单行显示和范围约束以用户最新要求为准；首版实施步骤仅供追溯。各轮按实际修改范围独立验证，不自动提交、推送或正式打包。当前交互规则统一维护于 [OPERATION_RESULTS](../../guides/OPERATION_RESULTS.md#统一操作设备入口)。

## 一、修改范围

只替换**当前已经有操作设备选择入口**的页面，不因共用组件而扩大显示范围。

| 当前已有入口的页面 | 选择方式 | 选择区内保留的操作 |
| --- | --- | --- |
| 文件管理 | 单选，可取消 | 清空选择；关闭当前文件管理会话 |
| 应用管理 | 单选，可取消 | 清空选择；关闭当前应用管理会话 |
| 实时 Logcat | 单选，可取消 | 清空选择；关闭当前日志会话 |
| 远程控制 | 多选 | 全选、清空选择 |
| 性能采集 | 多选 | 全选、清空选择 |
| 应用与诊断 | 多选 | 全选、清空选择 |
| 截图与屏幕 | 多选 | 全选、清空选择、清除截图结果 |
| 系统工具 | 多选 | 全选、清空选择 |

首页、设备概览、任务中心、设置等目前没有这个选择入口的页面不新增入口；第三轮仅调整设备概览标题与品牌展示，不改变连接区及设备卡动作。
原页面已有镜像、采集、录屏等开始/停止/重试按钮继续留在原处，不复制进每台设备行。

首版定位依据（行号对应首版工作树，后续以符号定位）：

- 同文件 `_sync_global_session_controls()` 2060–2085：现有设备栏可见范围、单选/多选及关闭动作投影。
- [DevicePicker](../../../gui/widgets/device_context_bar.py) 115–360：即时提交、全选/清空和当前会话关闭。
- [设备概览](../../../gui/pages/device_hub.py) `set_connection_panel()`：页内展开参考，透明底板、即时显隐。

### 信息密度

- 常驻内容为复选框、独立品牌与型号字段、Android 版本和连接方式（USB、无线或模拟器）；必要时在右侧追加一个短状态，例如“当前”“离线”“关闭中”。未知品牌隐藏字段及其分隔线，其余有效字段间使用纵向分隔线，设备行之间使用横向分隔线。
- 选择器、页头单设备名称和概览标题不带“设备 1/2”等编号前缀。概览保留有效 name/alias，否则以型号为标题，品牌作为独立辅助文字；任务结果、Monkey 和性能等原消费者继续使用全局稳定编号，编号分配、任务名称冻结和内部设备路由不变。
- 不显示 IP、序列号、电量、容量、包名、进度、帧率或逐设备任务阶段；显示名称沿用安全边界，不用真实设备标识补齐缺失名称。
- 不额外显示“已打开”“已有缓存”“未开启镜像”等普通状态，也不增加任务数量汇总和长说明行。
- 品牌、型号、版本和连接方式只从既有缓存投影；完整字段及现有必要解释进入 tooltip / accessible description，不新增 ADB 查询或业务状态采集。
- 空列表显示单行空态但保留五行区域高度；扫描或 ADB 不可用时在列表工具栏同一行显示短提示，不能把旧快照当成已确认在线。
- 字体使用 FontRole.UI，行高 `max(40, fontMetrics().height() + 18)`，同时保证容纳本行按钮；纵向居中，不出现第二行文字。

### 按钮归属

1. **列表级按钮**：全选、清空选择放在展开区头部同一行；单选页隐藏全选。截图页“清除截图结果”也放在这行，它属于整个图库，不属于某台设备。
2. **设备会话按钮**：文件、应用管理、Logcat 的原关闭动作放在当前会话对应设备行最右侧。只显示一个关闭按钮，非当前设备行不显示，保持原文案和 tooltip。
3. **当前设备不在候选中**：如果仍有原关闭动作，用一条紧凑的当前会话行承载“设备名称｜离线/关闭中｜关闭按钮”。该行不能勾选，不参与全选；不扩展成历史会话或任务列表。
4. **关闭语义不变**：仍关闭当前功能会话，不断开设备、不清空选择。关闭中原位禁用按钮并显示“正在关闭”，完成后按原流程收起选择区。
5. **无原有行操作**：不为了填满布局新增开始、停止、查看、重试或连接按钮。原正文里的业务操作保持原位和原目标归属。
6. 点击行内按钮只能触发该按钮，不能冒泡成设备勾选或切换；关闭动作不使用“最后点击的设备”作为目标。

### 对齐与窄窗

- 页头、列表和正文沿用左右各 32 个逻辑像素的阅读边界，不叠加旧浮层的 16 像素左右外边距。
- 透明底板承接 workspaceSurface，保留实际云母效果；使用字段纵向分隔线和行间横向分隔线帮助阅读。
- 选中状态仅由复选框表达，不显示蓝色行框；中性 hover 和键盘焦点反馈继续保留，方向键当前项始终可辨认。
- 品牌、型号、版本和连接方式按实际文字宽度紧凑左排；弹性留白只位于左侧信息组与右侧状态、动作之间，字段不拉伸占满整行。按钮使用一致高度与间距。
- 宽度不足时省略单行字段和“当前”等非关键状态，操作按钮转为同动作的图标按钮；完整字段和操作解释保留在 tooltip / accessible name 或 description。离线和关闭中的必要提示保留。
- 设备行和列表工具栏均不换行，不增加横向滚动，不强行扩大窗口；图标按钮仍可键盘访问。大字号按真实字体增加行高，不能裁切。
- 沿用即时展开/收起，不引入动画。收起后零占位，不留下独立关闭区或信息副行。

## 三、交互与业务约束

- 点击页头入口切换展开/收起；程序调用 `open_picker()` 仍为幂等打开，不能改成 toggle。
- 展开时入口保持 checked 状态，采用反向强调箭头和“收起设备”文案；收起后恢复原设备摘要和箭头方向。入口、全选、清空及行内动作统一使用无常驻背景的透明按钮。单设备摘要只显示安全名称，不带编号前缀。
- 点击设备行或勾选框即时提交一次；单选支持再次取消。多选完成后不自动收起。
- 切换物理页面或功能时收起；同功能换设备保持展开。点击正文不自动收起。
- 区域内 Esc 收起并回焦点；隐藏条目退出 Tab 链。不创建 Qt.Popup / Qt.Tool 或抢占主窗口激活。
- 保持现有候选与选择真源；不新增第二套可写设备集合或持久化展开状态。
- 单选页进入时不裁剪全局多选；用户明确选择时才同步操作目标与当前会话。
- 真实运行锁由原宿主控制；不能把正在加载、运行或只有一个候选解释为禁止切换。清空仍保留已有任务及原停止入口。
- 性能页多选不批量启动，原会话状态表继续决定当前查看/配置对象；系统和应用页的特定单设备动作仍在原按钮校验。
- 当前会话关闭必须复用原关闭屏障、重复提交保护和完成回调。页面切换后，旧按钮不能关闭新页面的会话。
- 列表刷新、名称返回、字体和主题更新不提交选择，不触发页面工厂、ADB、Monkey 准备或其它业务。
- 不显示或收集详细任务状态，因此取消此前为展示而新增 Remote/Monkey/录屏快照接口、通用 activity 数据模型的计划。

## 四、展开高度

- 固定预留五条单行设备项的高度；少于五台（包括空列表）也保留该高度，超过五行的内容在展开区内部纵向滚动。
- 用宿主内容面高度减去收起页头自然高度作为 H；展开区最多占 `floor(H × 0.45)`，保留正文空间。
- 选择区使用一条透明外层滚动条；列表本体容纳全部候选并关闭内部滚动，五行高度作用于选择区可见区域。极短窗口仍服从上述 45% 高度上限，不以五行要求挤占全部正文。
- 全选/清空及必要的当前会话行也属于同一滚动内容；短窗不新增另一套布局模式。
- 方向键改变当前项和 Tab 改变焦点时确保外层将目标滚动可见；列表区域滚轮不能被内部列表截留。
- 12→22→12 字号、正常→短窗→正常后恢复布局，不积累最小高度。
- 选择区高度规则不影响设备概览；第三轮概览仅让标题和独立品牌辅助文字参与自然高度计算，不改变连接区滚动或其他无选择入口页面的布局。
