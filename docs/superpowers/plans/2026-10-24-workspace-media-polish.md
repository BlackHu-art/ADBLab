# 工作区间距、导航焦点与截图页面调整

用户要求：底部恢复适度留白并上下统一，鼠标切页与点击截图时不出现蓝色键盘焦点框，
图片操作栏放底部，发送文本移出截图页，截图工具顶部与其他页对齐。

## 实施边界

- [x] 应用管理、文件管理嵌入模式上下外距统一为 8px；正文左右 32px 和贴边滚动条保持。
- [x] 主窗口在覆盖侧栏收起前按导航真实输入来源移交焦点，避免 Qt 重挂父控件产生的自动
  TabFocusReason 被误当作键盘操作；保留 Tab、反向 Tab 和键盘导航提示。
- [x] 截图页上下外距 8px，工具卡借入期间清零重复内距，归还时恢复；画布伸展，添加图片等
  命令位于画布下方。画布和分页仅显示键盘焦点，分页高度包含边框，避免圆点被裁切。
- [x] 发送文本移到应用与诊断页的“文本输入”分区。沿用原控件、信号和批量设备准入，切换或
  清除截图不丢输入、不重复发送，不改截图/录屏的任务与设备归属。
- [x] 同步四条新增文案的三语言词库及既有内嵌翻译资源，保留旧词条。
