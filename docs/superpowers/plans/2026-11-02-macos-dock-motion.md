# 投屏侧栏拖动与尺寸优化

用户要求：跟随更流畅、侧栏直接贴住镜像、按钮与主窗口尺寸体系一致。

- [x] 用失败回归固定零间隙贴边与 macOS 窗口事件订阅行为。
- [x] macOS 绑定身份后订阅 AX 移动/缩放等事件，回调只通知现有 GUI 合并刷新入口；
  保留周期生命周期检查及事件不可用时的轮询，关闭后释放通知和 RunLoop 引用。
- [x] 避免每帧全桌面窗口扫描，已验证窗口按原生窗口编号查询几何与可见性。
- [x] 侧栏取消横向空隙与顶部偏移；窄屏保留左右切换与工作区约束。
- [x] 按主窗口现有字体/控件度量缩小侧栏与更多按钮，保留大字号、快捷键、长按及便携模式。
- [x] 运行直接/关联测试、实际原生拖动与事件更新验证、Ruff/Pyright 和文档检查，独立只读复核。

实现保持会话进程与精确窗口身份约束，不激活或改变镜像，不更改设备操作、生产依赖或系统权限。
按钮尺寸与窗口跟随为独立文件范围并行实现；原生桌面验证串行进行，不自动提交或推送。

原生诊断补充：SDL 的单属性 AX 同步查询会累积阻塞，AXMoved 通知也可能被系统合并。
几何更新单独使用已绑定 CG 编号和 PID；空闲 60ms 采样，变化后 150ms 内按显示器刷新率
采样，完整身份核验仍由独立 250ms 计时器及输入入口负责。状态通知作废几何快路径，
临时注册失败按 1 秒节流重试。Windows/X11 保持原有事件与轮询策略。

## 附着侧栏焦点警告补充

关闭下拉菜单或切回窗口时出现 `requestActivate` / `WindowDoesNotAcceptFocus` 警告。
用 Cocoa 合成窗口确认：主宿主在前台时，附着 Tool 共享激活状态，子控件的 ClickFocus
会触发 Qt 为拒绝焦点的工具窗申请激活，并留下工具窗子控件的 Qt 焦点记录。
附着模式构造后移除子控件的鼠标焦点资格，保留原有 Tab 资格；便携模式保持原焦点规则。

- 原生点击回归修复前六项失败，修复后六项通过；另两项原生回归覆盖 Escape/外侧点击关闭
  菜单、切到合成镜像再切回主窗口，核对警告消失、焦点恢复且不重放设备操作，均通过。
- 工具栏/便携/材质/翻译离屏关联集 96 通过，Dock/合并刷新关联集 33 通过。
  Ruff、生产文件 Pyright、中文注释、文档链接与 diff 检查通过。独立只读复核无剩余发现。
- 补验旧原生跟随场景时，`test_macos_native_reactivating_stationary_mirror_restores_toolbar_stacking`
  曾在组合运行中一次超时；单独复跑及与前置无响应场景成对复跑均通过，未稳定复现原因。
  不把该组合描述为全绿；Windows 原生焦点行为未在本机实测，未重建分发包。
