# 右侧任务抽屉、任务中心与导航状态

用户已确认会话内交互预览，并授权整体实施、多 agent 开发、代码评审与测试。

## 目标与边界

- 普通功能页的任务反馈改为共享右侧抽屉，不跳转任务中心即可查看进度、逐台结果、完整输出和文件。
- 任务中心保留统一列表、搜索、类型与精确状态筛选，增加全部／进行中／异常／已结束快捷筛选。
  本次记录与已归档结果仍在同一列表，保留原有详情阅读、复制、导出、文件和参数复用能力。
- 导航任务图标反映所有已投影任务，不能受当前页、筛选、详情打开与否影响。
- 不改变业务命令、持久化格式、设备目标、依赖、版本或发布流程；不提交或推送。

## 已选方案

任务中心与普通功能页使用同一右侧抽屉。此前比较过原位反馈、收纳盒、任务窗、页内任务单、
设备透镜与临时输出面板，用户选择侧边抽屉，并确认任务中心列表与图标联动预览。

## 详情抽屉

- 主窗口内容面拥有唯一抽屉，与页面栈同级，覆盖右侧，不参与正文布局。
- 默认宽度 390 个逻辑像素，窄窗受宿主可用宽度限制；字号变化、DPI 和窗口调整不截断操作。
- 不透明主题底板；约 280 ms 的位置动画，只移动抽屉，不淡出正文、截图模糊或重建阅读器。
  连续反转从当前进度继续；隐藏、最小化和应用关闭停止动画，关闭中立即退出交互及 Tab 链。
- 同一任务更新保留正文选区、附件选择、滚动与身份；后台更新不抢走用户正在查看的其他任务。
  关闭提示不取消任务，晚到结果不重新打开关闭的抽屉。
- 显式查看可管理焦点，自动任务反馈不抢焦点。Esc 收起后归还仍有效的入口。
- 页面保留现有单例阅读器及有界正文缓存，固定挂到抽屉，不随列表行创建、删除或重挂。
- 取消仅调用原有停止入口，显示正在取消直到执行器确认；不伪造逐步进度、资源退出或成功结果。
- 只显示业务层已支持的操作。原型的通用“重试失败项”不能通过重放当前表单、重新选择文件或
  自动执行危险命令实现；未有安全重试契约的任务提供返回来源入口，避免重复执行成功设备。

## 状态图标

优先级：活动任务 > 未读异常 > 新成功提示 > 普通图标。

- 活动时蓝色进度环与逻辑任务数；存在未读异常时叠黄色点。
- 无活动、有未读异常时黄色状态；查看异常只消除未读，失败记录与异常筛选不改变。
- 明确观察到实时活动任务转为 succeeded，且无更高优先状态时显示绿色完成图标 3000 ms。
- 初次加载终态、历史归档、说明记录、重复快照、任务消失不触发完成提示。
- 新活动或新异常立即取消并丢弃旧成功提示；清除高优先状态后不恢复过时绿勾。
- 隐藏停止动画与成功计时，重新显示只恢复当前活动状态；shutdown 封闭更新并释放 Timer。

## 数据与集成

TaskCenterPage 继续合并 ActionResult、明确关联的 Operation 与 RunRecord/兼容历史，不另建业务状态源。
一个 Action request 关联多个 Operation 仍只计一个逻辑任务，未关联 Operation 独立计数。
隐藏页仍需更新数据投影，页面隐藏不等同于任务结束；主窗口提供有界 UI 线程刷新节拍。
任务快照与详情元数据通过信号交给主窗口，抽屉及导航控件不读取 Controller 或执行命令。

## 验证

直接回归覆盖动画中间帧、连续反转、resize、主题/字体、焦点、销毁；状态覆盖并发、取消屏障、
重复快照、初始历史、未读版本、超时和关闭。关联回归覆盖现有全文预算、附件、参数复用与导航。
macOS MainFrame / FluentWindow 使用 Cocoa，不能使用 offscreen 模拟原生句柄。
最终启动真实应用，操作展开收起并录制窗口逐帧核对，不能仅凭 Qt 单元测试声称无闪烁。

## 用户补充确认：持续会话

投屏、Logcat、性能采集一并进入任务中心。行身份绑定原资源 owner，不随当前页面、勾选或在线状态
改变。活动数以真实资源义务为准：启动、停止、清理或结果收尾期间均保持活动；停止失败可同时为
活动与未读异常。原停止入口继续拥有执行权，列表不复制停止算法。旧 revision 的按钮不得操作新
运行。手动停止、轮询消失、历史加载不产生成功动画；只有明确成功且真实释放后的转换可以产生。
状态投影不复制持续日志、不写新的持久化格式，不按标题/时间猜测合并归档。

性能资源状态使用纯内存投影，刷新允许通过现有受监督结果队列调度至多一个静默资源检查；
GUI 不等待运行锁、不检查目录/租约文件。检查保留原真实释放依据，完成后按代次交付缓存，
不更新图表、运行结果或用户正文；关闭和重复刷新不得新增失去归属的工作对象。

## 用户补充：崩溃、侧栏遮挡与样式统一

- 核对 macOS Python 崩溃记录，修正已确认的 Qt 调用/生命周期及测试安全边界；不能减少测试或
  隐藏系统弹窗来代替修复。无新原生崩溃和实际应用正常退出都要有证据。
- 覆盖层使用真实宿主合成画面验证不透明底板，包含头部、正文和底部；不能只抓子控件自身。
- 从展开到关闭动画最后一帧，可见侧栏覆盖的底层按钮均不可命中。关闭中侧栏自身退出操作，
  同时继续阻挡覆盖区域的 pointer；真正隐藏后恢复原命中。未覆盖区域保持原非模态操作。
- 关闭/隐藏/shutdown 中的侧栏动作（含程序和 Qt 辅助功能激活）不得继续执行；保持冻结的原任务
  key/revision 与后台更新。正文复制/导出/文件及参数动作也遵守宿主呈现资格。
- 沿既有 Fluent、FontRole、主题语义色与间距统一头部、内容及操作区，保持实色和可读层级；
  避免重复保留提示和过强的重复标题，不改业务 enabled 状态、持久化或执行目标。
