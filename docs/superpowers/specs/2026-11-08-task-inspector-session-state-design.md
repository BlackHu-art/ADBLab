## 当前任务检查器

- 用精简的单任务 inspector 重新整理层级，不把上一版只隐藏两个按钮作为完成。
  单一任务标题与关闭图标在顶区；状态、来源和脱敏目标为次级信息。避免“任务详情”大标题、
  任务名、历史条、请求摘要和正文重复抢占空间。允许短消息保留独立业务含义。
- 抽屉不展示任何最近/历史任务切换，不显示返回来源或在任务中心查看的底部导航按钮。
  任务中心页面的列表、筛选、历史和原任务选择行为继续保留。兼容 API/字段按最小范围保留，
  不让隐藏入口进入 Tab/无障碍树或承担新交互；没有真实消费者的私有 UI 逻辑可在证据下清理。
- 取消/停止仍可操作且语义明确，可纳入紧凑顶区/操作条；完成态不占用大块永久底栏。
  保留归档/本次数据保留含义，可用低权重文字或现有提示承载，避免重复的大段底部说明。
- 完整正文默认可见。搜索、复制/导出组成紧凑工具区，附件/参数在需要时直接显示。
  同一 reader/editor/按钮身份及 ReaderInteraction/TaskActionGesture 保留，独立/诊断/旧 inline
  默认不变；64K 显示预算、完整搜索/复制/导出、命令/请求级错误、设备明细均保留。
- 继续 Fluent 覆盖滚条、主题/强调色与 UI/LOG/MONO 角色热更新，保持当前任务、选区、搜索及
  附件身份；深浅、中文/英文、12/22pt、280/390px 均可读，新增控件复用现有 tr/图标/角色。
- 390逻辑像素、280ms纯位置动画、不透明遮挡及单例 reader 不变。外侧首击收起并消费整个
  手势、第二次普通点击可操作、popup/modal 与关闭资格、旧动作不跨 revision 的保证不变。

## 会话运行与忙碌分开

已由只读合成调用证实：connecting 和 ready 都投影 running/resource_owned=True；导航只看
active_count 就一直转圈。保留资源活动计数，追加只读忙碌信息：

- SessionTaskSnapshot 末尾 busy:bool=False；TaskNavigationSnapshot 末尾 busy_count:int|None=None。
  旧位置参数顺序不变，None仅兼容旧 active-only 调用；任务页显式给整数。
- 普通在途 ActionResult/Operation 算 busy；持续会话按 busy 或 starting/stopping/finalizing。
  稳定 running 的镜像、Logcat、性能仍 active、可停止，使用静态运行标识和数量，不旋转。
- Remote 只读地从原批次准备/连接/停止、启动/追加队列和真正排空状态计算 busy。
  一台 ready 加一台 preparing/connecting 仍忙；全 ready 且准备排空不忙。持续 reader 存活、
  FPS 输出或进程存在不能证明 busy 或 ready；保留原 process-key 就绪检查和真实资源释放边界。
- busy 参与快照相等性，connecting→ready 经原 collect/page/nav 更新；不进入异常已读版本，
  不改变 key/revision/原 owner/停止准入，不新增资源状态源、线程或定时器。
- 动画时钟只跟 busy；静态运行不能只是冻结一个加载缺口。活动、异常、成功优先级和成功事件
  的原终态规则保留，ready 不能制造完成。停止受理/排空中不能制造释放；既有明确 succeeded
  终态的成功提示保持，不借本需求改动已验收的完成语义。

## 验证与边界

UI 与导航投影分配给不同 writer，TaskPage 由会话任务独占，UI 不改它的导航统计；共享文档由
UI writer 统一。先安全红回归再最小实现；不得删/跳过/放宽有效测试。旧 history/footer UI 断言
按明确新要求迁移，任务中心数据与动作身份的有效断言保留。

Root 最终整合独立评审、Cocoa 关联测试、实际 main.py 与本机窗口录制。真实镜像须确认
connecting→ready 后资源和任务仍活动而动画停止，并停止本次创建的会话；不得干扰用户已有
会话。没有实际 ready 证据时不能假称镜像问题完成。未获授权不提交/推送/暂存/回退；不改
依赖/版本/CI/用户数据格式，旧阶段补丁与未提交资产保存。

## 最新补充：任务中心记录表格

用户要求移除任务状态切换筛选，并参考项目其他内容表格页面展示任务记录。
任务中心移除“全部 / 进行中 / 异常 / 已结束”切换及状态下拉，保留搜索和任务类型筛选。
状态作为表格内的信息与真实活动/异常计数继续呈现，不删除记录或改变原会话归属。
复用项目现有 Fluent/Qt 表格组件和样式，支持行选择、长文本、横向滚动、主题与字号；
详情打开同一个侧边检查器，取消/停止仍绑定原任务身份和代次，刷新不把动作移给其他任务。

## macOS 原生辅助功能兼容裁决

Qt 的原生 item view 行列辅助对象在当前公开运行时存在已确认的生命周期缺陷，实机动态记录
与层级查询可触发进程崩溃，官方已合入修复但公开稳定 wheel 尚未包含。用户要求的是与其他页面
一致的表格样式，并未指定控件技术。任务中心以项目既有稳定行控件呈现同样的表头、列对齐、
选择及横向滚动，保持字体、主题、原任务按钮和共享阅读器。不得通过关闭全局辅助功能、修改
Qt 私有运行时或隐藏失败来回避。早前‘复用 TableWidget’由此替换为复用表格视觉与控件体系；
验收按真实列内容、滚动、键盘、可访问操作和任务身份，不要求某一个 item view 类型。
