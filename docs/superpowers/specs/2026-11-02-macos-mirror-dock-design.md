# macOS 投屏侧栏窗口跟随

用户要求：macOS 侧边工具栏随本次镜像窗口移动、缩放、最小化和恢复。

- 在 `services/remote/windowing/` 增加 macOS 后端，继续使用既有窗口契约、进程后代与精确标题绑定、60ms 轮询及侧栏关闭流程。
- 使用现有 macOS 依赖 PyObjC 的 Accessibility/AppKit 接口；不新增依赖，不申请屏幕录制权限，不使用私有 API。
- 辅助功能授权不可用时使用既有便携工具栏，并记录可操作的授权诊断；不自动修改系统权限。
- AX 桌面坐标与 AppKit 坐标在后端转换，对外保持物理坐标契约；覆盖 Retina、负坐标副屏和工作区约束。
- 仅定位本进程侧栏，不移动或激活镜像；会话结束、替换或窗口身份失效后释放原生引用，不绑定其他同名窗口。
- 自动化使用原生接口替身和独立合成镜像窗口，不读取真实设备数据。Windows/Linux 行为保持。

采用辅助功能查询是因为它可以验证窗口标题及最小化状态；仅凭 CoreGraphics 枚举在未授权屏幕录制时不能可靠读取外部窗口标题。
